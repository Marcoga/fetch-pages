🗺️ The Master Strategy

We are leveraging Muscle Memory to reclaim lost size while using Bouldering to lean out and add high-definition detail. Because you want to boulder most days, the lifting is "low volume, high intensity" — we get in, move heavy weight to signal muscle retention, and get out.

🏋️ The Lifting Protocol

3 Sets per Exercise

Session A: The Foundation

  • Back Squat: 3 x 5 (Add 2.5kg each week)
  • Bench Press: 3 x 5 (Add 2.5kg each week)
  • Weighted Pull-ups: 3 x 8 (Bouldering back width)

Session B: The Power

  • Deadlift: 1 x 5 (Go heavy)
  • Overhead Press: 3 x 5 (Solid shoulders)
  • Barbell Rows: 3 x 10 (Thickening the lats)

Session C: The Summer Build

  • Incline DB Press: 3 x 10 (Upper chest focus)
  • Bulgarian Split Squats: 3 x 10 (Leg definition)
  • Dips: 3 x Max (Chest/Tricep pump)

✨ Aesthetics Finisher

Add these to the end of every lift session to hit those "Look Great Naked" goals:

  • Hanging Leg Raises: 3 x 15 (Core/V-Line)
  • Hammer Curls: 3 x 12 (Thick forearms/arms)
  • Face Pulls: 3 x 15 (Posture/Shoulder health)

🥗 Nutrition Targets

Calories: Maintenance minus 200-300 kcal.

Protein: Aim for ~160g - 180g total daily.

Carbs: Cycle higher on Bouldering Project days. Keep them low on rest days.

📈 3-Month Roadmap

Month 1: Re-Activation

Focus on perfect form. Muscle memory will start to "fill out" your frame. Bouldering should focus on Volume (sending lots of 5s) to prep tendons.

Month 2: The Momentum

Weights should be getting heavy. Start Projecting (Limit Bouldering) on the wall. This is where the most fat loss occurs.

Month 3: The Peak

Tighten the deficit slightly if needed. High-intensity bouldering. This is the "Look Great Naked" final polish phase.
