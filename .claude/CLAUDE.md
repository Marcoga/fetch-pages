# fetch-pages

This is Marco's static file hosting repo, served via **GitHub Pages** at:
**https://marcoga.github.io/fetch-pages/**

## Publishing static files

To make any file publicly accessible, copy it into this directory and push to `master`:

```bash
cp /path/to/file.mp4 /Users/marco/personal/fetch-pages/
cd /Users/marco/personal/fetch-pages
git add <filename>
git commit -m "Add <description>"
git push
```

GitHub Pages auto-publishes within ~1 minute. The public URL is:
`https://marcoga.github.io/fetch-pages/<filename>`

## What goes here

- HTML pages generated by Claude agents (reports, dashboards, explainers)
- Images and screenshots for sharing
- Videos and other media for linking in Notion tasks
- Any asset that needs a public URL
